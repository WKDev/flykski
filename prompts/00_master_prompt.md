# flykski — 마스터 프롬프트 (v2: flybody 기반 재설계)

## 개정 배경
초기 설계(v1)는 물리 바디·제어 API를 처음부터 만드는 것을 전제로 했다. 조사 결과 이미 검증된 오픈소스/논문 파이프라인이 존재해, 이를 재사용하는 쪽이 훨씬 현실적이다.

- **[flybody](https://github.com/TuragaLab/flybody/)** (Google DeepMind × HHMI Janelia): MuJoCo 기반 초파리 생체역학 모델. 67개 body part, 66개 관절, 총 102 자유도. **단, 액션(제어) 차원은 전신 자유도와 다르다** — 공식 보행(walking) 예제의 액션 차원은 59다. 관절 액추에이터, 보행/비행 사전학습 컨트롤러 포함. Nature 논문 "Whole-body physics simulation of fruit fly locomotion"으로 검증됨.
- **FlyGM**(Jin, Zhu, Zhang, Sui, "Whole-Brain Connectomic Graph Model Enables Whole-Body Locomotion Control in Fruit Fly", arXiv 2602.17997): **FlyWire(뇌만, VNC 미포함) 커넥톰**의 실제 위상(afferent/intrinsic/efferent)을 고정하고 뉴런별 소수 학습 파라미터(내재 기술자)만 학습해, flybody 사전학습 컨트롤러의 시연 궤적으로 모방학습(IL) 워밍업 후 PPO로 미세조정. 자신의 실험 설정 안에서 재배선/랜덤 그래프·MLP보다 낮은 오차를 보임. **본 프로젝트는 다른 커넥톰(MaleCNS)·다른 과제를 쓰므로 이 결과가 그대로 재현된다고 가정하지 않고, 검증 대상 가설로 다룬다**(업무4/5).
- 초파리 걷기의 CPG 회로를 VNC 커넥톰 시뮬레이션으로 찾은 연구(Pugliese et al., "Connectome simulations identify a central pattern generator circuit for fly walking", bioRxiv 10.1101/2025.09.12.675944): 하행뉴런 DNg100과 억제성 1+흥분성 2 인터뉴런 회로가 리듬 생성에 핵심임을 밝힘. **개방루프 리듬 생성 검증까지가 논문의 범위이며, 폐루프 보행 제어나 우리 프로젝트의 관절 액추에이션 디코딩은 검증되지 않은 신규 작업**임을 업무4에서 명시한다.
- NeuroMechFly/FlyGym 계열은 후각 플룸을 추적하는 취주(odor-taxis) 내비게이션도 이미 지원 — 이번 재설계의 핵심 아이디어(아래) 근거.
- **교차검증(codex CLI, 2026-09-23) 반영**: 위 사실관계 오류(FlyWire/MaleCNS 혼동, 액션 차원, 논문 결과 승계 가정) 및 아래 두 가지 설계 결함 — (a) 좌/우 트라이포드를 스키 하나에 rigid weld하는 과구속 설계, (b) 냄새 게이트 동시 다중 활성화로 인한 기울기 간섭 — 을 이번 개정에서 수정했다. 세부 내용은 각 업무 파일 참고.

## 핵심 재설계 아이디어
1. **바디를 새로 만들지 않는다.** flybody의 다리·관절 구조를 그대로 쓰고, 스키는 다리(정확히는 tarsus 말단)마다 독립적으로 부착하는 추가 강체로 설계한다(다리 6개를 하나의 스키에 묶는 rigid weld는 과구속을 유발하므로 사용하지 않는다 — 업무2 참고).
2. **"조종 파라미터 → 물리" 라는 하향식 제어 API를 폐기한다.** 실제 행동은 flybody의 관절 액추에이터(차원은 태스크에 따름, 하드코딩 금지)로 나오고, 엣지각·하중배분 같은 스키 지표는 그 결과에서 **역산(derive)** 한 텔레메트리로 취급한다 (FlyGM이 "efferent 뉴런 → 관절 액추에이터"로 직접 디코딩한 방식을 따름).
3. **목표 궤적을 사람이 정의하지 않는다.** 슬로프에 좌우로 번갈아 배치한 **냄새원(odor source, 슬라롬 게이트 역할)**을 두고, 초파리의 실제 후각 내비게이션 회로(취주 반응)가 냄새 농도 기울기를 따라가도록 만든다. **게이트는 한 번에 하나만 활성화**해 여러 냄새 소스의 기울기 간섭을 막는다(순차 점화, 업무1). 게이트가 좌우로 번갈아 있으면 자연스럽게 S자 커브가 나온다. **이 게이트 시퀀스 자체가 학습 평가(업무5)의 ground-truth 경로가 된다** — 사람이 "이상적인 라인"을 임의로 정의할 필요가 없어짐.

## 전체 아키텍처
```
[업무1] 무한 슬로프(모글/알파인, 설질) + 슬라롬형 냄새원(odor gate) 필드
        │  (지형 heightfield/mesh, 설질 파라미터, 냄새 농도장)
        ▼
[업무2] flybody 다리에 부착되는 스키 프로파일(강체 지오메트리 + 접촉 파라미터)
        │
        ▼
[업무3] 스키 부착 통합 + flybody 관절 액추에이터 실제 구동
        │  (센서: 관절각/각속도, 발바닥 접촉력, 냄새 농도/기울기, 자세)
        ▼
[업무4] MaleCNS 커넥톰 기반 컨트롤러 (다리 CPG 경로 + 후각 스티어링 경로)
        │  → 관절 액추에이션으로 디코딩 (FlyGM 방식 참고, 차원은 업무3 action_dim)
        ▼
[업무5] 반복 학습 세션: 게이트 통과 성공률/순서/방향으로 "S자 커빙 정확도" 평가
```

## 공통 규약 (변경분)
- **엔진 고정**: MuJoCo (flybody와 동일). 지형은 MuJoCo `hfield`(heightfield) 애셋을 기본으로 한다. hfield는 `nrow`/`ncol`이 컴파일 시 고정되지만 `hfield_data`는 런타임 교체 가능(렌더링 반영에는 `mjr_uploadHField` 필요) — 업무1은 이 제약 위에서 (1단계) 유한 긴 코스 → (2단계) 접촉 중이 아닌 영역만 갱신하는 윈도우 방식 + 재중심화 조합으로 "무한"을 구현한다.
- **베이스라인 비교 조건 필수화**: 모든 실험은 (a) flybody 사전학습 보행 컨트롤러 + 하드코딩 후각 취주(순수 엔지니어링 베이스라인), (b) 커넥톰 위상 고정 + 학습 게인(제안 방식), (c) 랜덤/셔플 그래프(대조군) 세 조건을 비교한다. FlyGM 논문의 검증 방법론을 그대로 따르는 것이며, "커넥톰이 실제로 기여하는가"를 매 실험에서 증명해야 한다.
- 기존 좌표계(Z-up, +X 하강방향)와 재현성(seed 고정) 규약은 v1과 동일하게 유지.

## 진행 방식 권장
1. flybody를 그대로 불러와 평지에서 사전학습 컨트롤러가 걷는지부터 확인(환경 세팅 검증).
2. 01의 **1단계(유한 긴 코스 + 순차 냄새 게이트)** 를 flybody 월드에 통합, 02(N=6 미니 스키)~03을 얹어 "사전학습 컨트롤러 + 하드코딩 취주"만으로 게이트를 통과하며 활강하는 베이스라인을 먼저 완성한다. 무한 스트리밍(01의 2단계)은 이 베이스라인이 안정된 뒤 확장한다.
3. 04(커넥톰 컨트롤러)를 베이스라인과 교체 가능한 플러그인으로 구현.
4. 05에서 세 조건(베이스라인/커넥톰/랜덤그래프)을 동일 세션으로 비교 평가한다.
